How this works

This practice test mirrors the real AWS Certified Cloud Practitioner (CLF-C02) format: 65 questions in 90 minutes, of which 50 are scored and 15 are unscored pretest items — you won’t know which is which, exactly like the real exam. Only the 50 scored questions count toward a scaled score out of 1000, where 700 is a pass (this mock weights all scored questions equally, so 35 correct = 700). Questions are drawn at random from a larger bank across the four course modules and reshuffled each attempt. Multiple-response questions must be fully correct to earn the point. You can flag questions and revisit them before submitting. At the end you get a pass/fail result, a per-module breakdown and full explanations.
